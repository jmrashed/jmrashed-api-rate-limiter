# Contributing to Jmrashed API Rate Limiter

First off, thank you for considering contributing to Jmrashed API Rate Limiter! It's people like you that make the open source community such a great place.

## How Can I Contribute?

There are many ways you can contribute to this project. You can:

*   [Report a bug](#reporting-bugs)
*   [Suggest a new feature](#suggesting-new-features)
*   [Write code](#writing-code)
*   [Improve the documentation](#improving-the-documentation)

### Reporting Bugs

If you find a bug, please open an issue on our [GitHub repository](https://github.com/jmrashed/jmrashed-api-rate-limiter/issues). Please include as much information as possible in your issue, including:

*   A clear and concise description of the bug.
*   Steps to reproduce the bug.
*   The expected behavior.
*   Screenshots (if applicable).
*   Your operating system and browser version.

### Suggesting New Features

If you have an idea for a new feature, please open an issue on our [GitHub repository](https://github.com/jmrashed/jmrashed-api-rate-limiter/issues). Please include as much information as possible in your issue, including:

*   A clear and concise description of the feature.
*   The problem that the feature would solve.
*   Any potential drawbacks of the feature.

### Writing Code

If you want to write code, please follow these steps:

1.  Fork the repository.
2.  Create a new branch for your changes.
3.  Make your changes.
4.  Run the tests.
5.  Commit your changes.
6.  Push your changes to your fork.
7.  Open a pull request.

### Improving the Documentation

If you want to improve the documentation, please follow these steps:

1.  Fork the repository.
2.  Create a new branch for your changes.
3.  Make your changes.
4.  Commit your changes.
5.  Push your changes to your fork.
6.  Open a pull request.

## Style Guide

This project follows the [Airbnb JavaScript Style Guide](https://github.com/airbnb/javascript). Please ensure that your contributions adhere to this style guide.

## Code of Conduct

Please read our [Code of Conduct](https://github.com/jmrashed/jmrashed-api-rate-limiter/blob/main/CODE_OF_CONDUCT.md) before contributing.
